tDiary 5.7.0 をリリースします。今回は日記の更新画面を書きやすくし、Rack で動かすときの Basic 認証を bcrypt 方式のパスワードに切り替えました。

## 本体(tdiary-core)の変更点

### 画面を移らずに見られるプレビュー

更新画面で「プレビュー」ボタンを押すと、フォームの上にプレビューが出るようになり、画面は移りません。書く画面とプレビューは Cmd+Shift+P (Windows と Linux なら Ctrl+Shift+P) で切り替えられます。JavaScript が動かないときは、これまでどおりプレビューの画面へ移ります。

preview.rb による横並びのプレビューは、入力が止まって 1 秒たつと更新されるようになりました。これに伴い、更新間隔の設定はなくなりました。

### 書いた本文を失わない更新画面

これまでの更新画面では、操作によって書いた本文が失われることがありました。存在しない日付のときや、ほかの場所で先に更新されていたときは、書いた本文ごとフォームに戻り、理由も表示します。

タイトル欄で Enter を押すと、本文の入力欄へ移るだけになりました。保存ボタンを二度押しても、送るのは一度だけです。保存していない本文があれば、画面を離れる前に確認します。

draft.rb は、ブラウザとサーバーに下書きを保存した時刻も表示します。フォームを開いたとき、そこに書きかけの下書きが残っていれば、読み込むかどうか尋ねます。

### 本文の入力欄

本文の入力欄は、ページと同じフォントを 16px 以上の大きさと広めの行間で表示するようになりました。field-sizing を使えるブラウザでは、入力欄が本文に合わせて画面の高さの 75% まで伸びます。

preview.rb を使うと、更新画面とプレビューが横に並びます。このとき image.rb の画像一覧がはみ出していた問題を直し、一覧が列の幅で折り返すようにしました。

### スマートフォンとタブレットでの設定画面

設定画面は、スマートフォンやタブレットの幅でも横にはみ出さなくなりました。幅 640px 未満では、メニューをフォームの上に並べます。

### Basic 認証のパスワードを bcrypt 方式に

Rack で動かすときの Basic 認証が、.htpasswd の bcrypt 方式のパスワードを扱えるようになりました。これまでの CRYPT 方式はパスワードの先頭 8 文字しか使わず、Ruby でも String#crypt を非推奨にする方針が示されています。

tdiary htpasswd コマンドは bcrypt 方式でパスワードを書くようになりました。Apache の htpasswd コマンドで作るときは、htpasswd -cB .htpasswd ユーザ名 のように -B オプションを付けてください。コマンドが動かせないサーバーでも、手元のパソコンから作ったファイルを置けば使えます。

CRYPT 方式の .htpasswd でも当面はログインできますが、更新画面に作り直しを促すメッセージが出ます。tdiary htpasswd で作り直すときは、先に .htpasswd を削除してください。

bcrypt gem は C 拡張なので、Gemfile の rack グループに置き、パッケージ版から外しています。Web サーバーで認証する CGI の環境には影響しません。

gem 版の tdiary は、新たに bcrypt gem を必要とします。Windows の mswin 版 Ruby では、今のところ bcrypt gem をインストールできません。

### 楽天ブックスでの JAN コードの検索

amazon_rakuten.rb は、ISBN のほか JAN コードでも楽天ブックスの商品を探せるようになりました。雑誌や DVD、ゲームのように JAN コードしかない商品でも、名前と画像を表示できます。楽天ブックスでも見つからないときは、書籍なら Amazon の ISBN-10 のページへ、JAN コードなら Amazon の検索結果へリンクします。

### そのほかの修正

* image.rb で複数の画像を一度にアップロードすると、最後の 1 枚しか保存されないことがある問題を修正
* アップロードされたファイルを cgi.rb と同じ形で扱う image_ex.rb などのプラグインが、動かなくなっていた問題を修正
* 古い版の tDiary が保存したプラグインのデータを読み込むと、makerss.rb のエラーで起動しない問題を修正
* Bundler 4 で tdiary new、tdiary update、tdiary test が動かなくなっていた問題を修正
* 必要な rack gem の版を 3.2 以上に変更

## theme (tdiary-theme)の変更点
* とくになし

## blogkit (tdiary-blogkit)の変更点
* とくになし

## contrib (tdiary-contrib)の変更点

* comment_pushbullet.rb が使う pushbullet_ruby gem を、tdiary-contrib の依存から外しました。pushbullet_ruby が古い版の faraday に依存しているためです。comment_pushbullet.rb を使う場合は、Gemfile.local に gem 'pushbullet_ruby' と書き足してください。
* hatena_star.rb は、セクションのアンカーが無い日でも、日付へスターを付けられるようになりました。AutoPagerize で継ぎ足したページにもスターが出ます。
* image_ex.rb は、ファイルを選ばないまま送信してもエラーにならなくなりました。
* tdiary-mode.el は、日記の更新後のリダイレクトで接続がタイムアウトしなくなりました。
